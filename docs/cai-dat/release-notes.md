Bản cài đặt Tinh Tú Ước Nguyện. Hướng dẫn cài từng nền tảng: [docs/cai-dat/README.md](https://github.com/Dungeon067/DUngeon/blob/main/docs/cai-dat/README.md).

| Máy           | Tải file                                                               |
| ------------- | ---------------------------------------------------------------------- |
| Android       | `TinhTu_…_android.apk`                                                 |
| Windows       | `TinhTu_…_windows_x64-setup.exe` (hoặc `.msi`)                         |
| macOS         | `TinhTu_…_macos_universal.dmg` (chưa ký: chuột phải vào ứng dụng → Mở) |
| Linux         | `TinhTu_…_linux_x86_64.AppImage`                                       |
| iPad / iPhone | Mở bản web bằng Safari → Chia sẻ → Thêm vào MH chính                   |

APK ký bằng khoá thử (debug keystore công khai trong repo), chỉ dùng để chơi thử. Bản Windows và macOS chưa ký mã nên hệ điều hành sẽ cảnh báo lần đầu mở.
